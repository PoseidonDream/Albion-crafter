Focus cost = base × 0.5^(efficiency ÷ 10,000). Each mastery level gives 30 efficiency, each level of an item's own specialization 250, and every specialization level in the same mastery adds 30 (18 for potions) to all its items. The percentage under each box is how much less focus that item costs with these levels. If a number doesn't match the game, type the focus cost the game shows for that item on the Crafting page.
